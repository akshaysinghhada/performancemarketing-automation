# Performance Marketing Automation Toolkit

An open-source AI-powered toolkit that automates performance marketing workflows using the Claude API.

## What It Does

- **Ad Creative Generation:** Uses Claude API to generate high-converting ad copy for Meta and Google Ads.
- **Campaign Analysis:** Analyzes campaign data and provides actionable optimization insights.
- **Audience Targeting:** AI-driven audience research and targeting recommendations.
- **Automated Reporting:** Generates weekly performance reports from ad platform data.

## Tech Stack

- Python 3.10+
- Claude API (Anthropic)
- Meta Marketing API
- Google Ads API
- Pandas, Requests, Streamlit

## Why This Project Exists

Most performance marketers waste 10-15 hours per week on repetitive tasks like writing ad variations, analyzing reports, and researching audiences. This toolkit automates those tasks so marketers can focus on strategy.
